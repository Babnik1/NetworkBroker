Network Broker

Небольшой асинхронный брокер сообщений на C++17, обеспечивающий обмен сообщениями между несколькими клиентами по сети.

Проект реализован с использованием Boost.Asio и построен по принципу брокера сообщений: клиенты подключаются к серверу, регистрируются или авторизуются, создают тематические каналы, подписываются на них и публикуют сообщения.

Брокер самостоятельно определяет, каким подписанным клиентам необходимо доставить опубликованное сообщение.

Возможности

  • асинхронная обработка TCP-соединений;
  • одновременная работа с несколькими клиентами;
  • регистрация и авторизация клиентов;
  • создание тематических каналов;
  • подписка и отписка клиентов от каналов;
  • публикация сообщений;
  • маршрутизация сообщений подписчикам;
  • хранение клиентов и топиков в JSON;
  • многопоточная обработка журналирования;
  • конфигурация приложения через JSON;
  • логирование событий приложения;
  • модульные тесты;
  • интеграционные тесты;
  • автоматическая сборка и тестирование через GitHub Actions;
  • автоматическая генерация документации Doxygen.

Основные компоненты

Server

Отвечает за TCP-соединения и принимает новых клиентов с помощью Boost.Asio.

Session

Представляет отдельное сетевое соединение с клиентом и взаимодействует с брокером.

MessageBroker

Центральный компонент приложения. Разбирает команды клиента и передаёт их соответствующим менеджерам.

ClientManager

Управляет зарегистрированными клиентами, их подключением и соответствием между SessionId и ClientId.

TopicManager

Управляет тематическими каналами и списками их подписчиков.

JSON repositories

Отвечают за сохранение и загрузку данных клиентов и топиков.

Logger

Выполняет асинхронное журналирование через потокобезопасную очередь. Запись сообщений в файл выполняется отдельным потоком.

Протокол

Клиент взаимодействует с брокером посредством простого текстового протокола.

Регистрация

REGISTER <name>

Пример:

REGISTER alex

Ответ:

OK

Авторизация

LOGIN <name>

Пример:

LOGIN alex

Создание топика

CREATE <topic>

Пример:

CREATE news

Подписка

SUBSCRIBE <topic>

Пример:

SUBSCRIBE news

Отписка

UNSUBSCRIBE <topic>

Публикация

PUBLISH <topic> <message>

Пример:

PUBLISH news Hello world

Сообщение будет отправлено клиентам, подписанным на указанный топик.

Ответы сервера

При успешном выполнении команды сервер возвращает:

OK

При ошибке:

ERROR <description>

Например:

ERROR Client not found
ERROR Topic not found
ERROR Already subscribed
ERROR You are unauthorized
ERROR Invalid command

При запуске менеджеры загружают данные из соответствующих JSON-файлов.

Логирование выполняется через потокобезопасную очередь:

Основной поток приложения не выполняет непосредственно запись каждого сообщения в файл. Логирование передаётся отдельному потоку, который последовательно обрабатывает очередь сообщений.
